# Stormworks Dedicated Server

Dedicated server support for Stormworks. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [1247090](https://steamdb.info/app/1247090/info/).

## Defaults
| | |
|---|---|
| Game port | 25564 |
| Query port | 25564 |
| Max players | 32 |
| Query protocol | none |
