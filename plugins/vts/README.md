# Vintage Story Dedicated Server

Dedicated server support for Vintage Story. Install, run, configure and monitor it from NodeGSM.

## Install
Downloaded automatically by the plugin (see `plugin.js`).

## Defaults
| | |
|---|---|
| Game port | 42420 |
| Query port | 42420 |
| Max players | 16 |
| Query protocol | none |

## Config files
- **serverconfig.json** (`data/serverconfig.json`, json) - Server name, port, password, world config

## Logs
- **server-main.txt** (`data/Logs/server-main.txt`)

## Notes
Downloads the latest stable server zip from vintagestory.at.

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
