# Outlaws of the Old West Dedicated Server

Dedicated server support for Outlaws of the Old West. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [915070](https://steamdb.info/app/915070/info/).

## Defaults
| | |
|---|---|
| Game port | 27374 |
| Query port | 27015 |
| Max players | 24 |
| Query protocol | a2s |
