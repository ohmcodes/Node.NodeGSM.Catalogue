# Left 4 Dead 2 Dedicated Server

Dedicated server support for Left 4 Dead 2. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [222860](https://steamdb.info/app/222860/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27015 |
| Max players | 24 |
| Query protocol | a2s |

## Config files
- **server.cfg** (`left4dead2/cfg/server.cfg`, cfg) - Main server config (hostname, rcon_password, ...)

## Logs
- **Server logs** (`left4dead2/logs/*.log`)
