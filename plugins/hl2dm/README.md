# Half-Life 2: Deathmatch Dedicated Server

Dedicated server support for Half-Life 2: Deathmatch. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [232370](https://steamdb.info/app/232370/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27015 |
| Max players | 24 |
| Query protocol | a2s |

## Config files
- **server.cfg** (`hl2mp/cfg/server.cfg`, cfg) - Main server config (hostname, rcon_password, ...)

## Logs
- **Server logs** (`hl2mp/logs/*.log`)
