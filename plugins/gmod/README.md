# Garry's Mod Dedicated Server

Dedicated server support for Garry's Mod. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [4020](https://steamdb.info/app/4020/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27015 |
| Max players | 24 |
| Query protocol | a2s |

## Config files
- **server.cfg** (`garrysmod/cfg/server.cfg`, cfg) - Main server config (hostname, rcon_password, ...)

## Logs
- **Server logs** (`garrysmod/logs/*.log`)
