# Empyrion - Galactic Survival Dedicated Server

Dedicated server support for Empyrion - Galactic Survival. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [530870](https://steamdb.info/app/530870/info/).

## Defaults
| | |
|---|---|
| Game port | 30000 |
| Query port | 30001 |
| Max players | 8 |
| Query protocol | none |

## Config files
- **dedicated.yaml** (`dedicated.yaml`, yaml) - Server name, ports, player limit
