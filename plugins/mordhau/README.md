# Mordhau Dedicated Server

Dedicated server support for Mordhau. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [629800](https://steamdb.info/app/629800/info/).

## Defaults
| | |
|---|---|
| Game port | 7777 |
| Query port | 27015 |
| Max players | 16 |
| Query protocol | a2s |

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
