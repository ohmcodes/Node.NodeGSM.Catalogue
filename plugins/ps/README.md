# Post Scriptum Dedicated Server

Dedicated server support for Post Scriptum. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [746200](https://steamdb.info/app/746200/info/).

## Defaults
| | |
|---|---|
| Game port | 10027 |
| Query port | 10037 |
| Max players | 80 |
| Query protocol | a2s |

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
