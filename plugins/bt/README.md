# Barotrauma Dedicated Server

Dedicated server support for Barotrauma. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [1026340](https://steamdb.info/app/1026340/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27016 |
| Max players | 10 |
| Query protocol | none |

## Config files
- **serversettings.xml** (`serversettings.xml`, xml) - Server name, ports, game rules
