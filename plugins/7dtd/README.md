# 7 Days to Die Dedicated Server

Dedicated server support for 7 Days to Die. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [294420](https://steamdb.info/app/294420/info/).

## Defaults
| | |
|---|---|
| Game port | 26900 |
| Query port | 26900 |
| Max players | 8 |
| Query protocol | none |

## Config files
- **serverconfig.xml** (`serverconfig.xml`, xml) - Server name, ports, world, game rules

## Logs
- **Server log** (`7DaysToDieServer_Data/output_log_dedi*.txt`)

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
