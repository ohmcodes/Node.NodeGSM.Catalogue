# Team Fortress 2 Dedicated Server

Dedicated server support for Team Fortress 2. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [232250](https://steamdb.info/app/232250/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27015 |
| Max players | 24 |
| Query protocol | a2s |

## Config files
- **server.cfg** (`tf/cfg/server.cfg`, cfg) - Main server config (hostname, rcon_password, ...)

## Logs
- **Server logs** (`tf/logs/*.log`)

## Contributing
