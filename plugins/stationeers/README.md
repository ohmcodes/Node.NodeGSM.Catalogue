# Stationeers Dedicated Server

Imported from the WindowsGSM community plugin [Nopus64/WindowsGSM.STATIONEERS](https://github.com/Nopus64/WindowsGSM.STATIONEERS) (plugin author: Nopus, repository license: MIT).
Only metadata (name, app id, executable, start command line, default ports) was extracted automatically; no C# code was copied or executed. The game server software belongs to its publisher.

**Install is manual for now**: this plugin's original code used custom download logic that still needs a NodeGSM install step.

Not tested yet. The icon is a placeholder.
