# Insurgency: Sandstorm Dedicated Server

Dedicated server support for Insurgency: Sandstorm. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [581330](https://steamdb.info/app/581330/info/).

## Defaults
| | |
|---|---|
| Game port | 27102 |
| Query port | 27131 |
| Max players | 28 |
| Query protocol | a2s |
