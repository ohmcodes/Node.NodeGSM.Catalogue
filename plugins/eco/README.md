# Eco Dedicated Server

Dedicated server support for Eco. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [739590](https://steamdb.info/app/739590/info/).

## Defaults
| | |
|---|---|
| Game port | 3000 |
| Query port | 3001 |
| Max players | -1 |
| Query protocol | none |

## Config files
- **Network.eco** (`Configs/Network.eco`, json) - Server name, ports, password

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
