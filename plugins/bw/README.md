# BlackWake Dedicated Server

Dedicated server support for BlackWake. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [423410](https://steamdb.info/app/423410/info/).

## Defaults
| | |
|---|---|
| Game port | 25001 |
| Query port | 25002 |
| Max players | 54 |
| Query protocol | none |
