# Onset Dedicated Server

Dedicated server support for Onset. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [1204170](https://steamdb.info/app/1204170/info/).

## Defaults
| | |
|---|---|
| Game port | 7777 |
| Query port | 7776 |
| Max players | 100 |
| Query protocol | none |

## Config files
- **server_config.json** (`server_config.json`, json) - Server name, ports, packages

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
