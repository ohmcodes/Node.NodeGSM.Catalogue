# Heat Dedicated Server

Dedicated server support for Heat. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [996600](https://steamdb.info/app/996600/info/).

## Defaults
| | |
|---|---|
| Game port | 7450 |
| Query port | 7450 |
| Max players | 40 |
| Query protocol | none |
