# Avorion Dedicated Server

Dedicated server support for Avorion. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [565060](https://steamdb.info/app/565060/info/).

## Defaults
| | |
|---|---|
| Game port | 27000 |
| Query port | 27003 |
| Max players | 10 |
| Query protocol | a2s |

Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
