# Space Engineers Dedicated Server

Dedicated server support for Space Engineers. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [298740](https://steamdb.info/app/298740/info/).

## Defaults
| | |
|---|---|
| Game port | 27016 |
| Query port | 27017 |
| Max players | 4 |
| Query protocol | a2s |
