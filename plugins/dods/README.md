# Day of Defeat: Source Dedicated Server

Dedicated server support for Day of Defeat: Source. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [232290](https://steamdb.info/app/232290/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27015 |
| Max players | 24 |
| Query protocol | a2s |

## Config files
- **server.cfg** (`dod/cfg/server.cfg`, cfg) - Main server config (hostname, rcon_password, ...)

## Logs
- **Server logs** (`dod/logs/*.log`)

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
