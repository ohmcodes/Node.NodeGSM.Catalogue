# Reign Of Kings Dedicated Server

Dedicated server support for Reign Of Kings. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [381690](https://steamdb.info/app/381690/info/).

## Defaults
| | |
|---|---|
| Game port | 7350 |
| Query port | 7350 |
| Max players | 30 |
| Query protocol | none |
