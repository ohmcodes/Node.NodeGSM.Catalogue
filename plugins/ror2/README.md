# Risk of Rain 2 Dedicated Server

Dedicated server support for Risk of Rain 2. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [1180760](https://steamdb.info/app/1180760/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27016 |
| Max players | 4 |
| Query protocol | a2s |
