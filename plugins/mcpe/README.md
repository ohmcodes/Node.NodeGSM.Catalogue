# Minecraft: Pocket Edition Server (PocketMine-MP)

Dedicated server support for Minecraft: Pocket Edition (PocketMine-MP). Install, run, configure and monitor it from NodeGSM.

## Install
No automatic installer - use **Import** and point NodeGSM at an existing install.

## Defaults
| | |
|---|---|
| Game port | 19132 |
| Query port | 19132 |
| Max players | 20 |
| Query protocol | ut3 |

## Config files
- **pocketmine.yml** (`pocketmine.yml`, yaml)
- **server.properties** (`server.properties`, properties)

## Logs
- **server.log** (`server.log`)

## Notes
No automatic installer. Download the PocketMine-MP Windows build from <https://github.com/pmmp/PocketMine-MP/releases> and use **Import**.

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
