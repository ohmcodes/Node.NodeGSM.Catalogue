# No More Room in Hell Dedicated Server

Dedicated server support for No More Room in Hell. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [317670](https://steamdb.info/app/317670/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27015 |
| Max players | 24 |
| Query protocol | a2s |

## Config files
- **server.cfg** (`nmrih/cfg/server.cfg`, cfg) - Main server config (hostname, rcon_password, ...)

## Logs
- **Server logs** (`nmrih/logs/*.log`)
