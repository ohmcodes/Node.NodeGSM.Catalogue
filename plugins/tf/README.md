# The Forest Dedicated Server

Dedicated server support for The Forest. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [556450](https://steamdb.info/app/556450/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27016 |
| Max players | 4 |
| Query protocol | none |

## Config files
- **Server.cfg** (`Server.cfg`, cfg) - Server name, ports, password
