# Squad Dedicated Server

Dedicated server support for Squad. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [403240](https://steamdb.info/app/403240/info/).

## Defaults
| | |
|---|---|
| Game port | 7787 |
| Query port | 27165 |
| Max players | 80 |
| Query protocol | a2s |

## Config files
- **Server.cfg** (`SquadGame/ServerConfig/Server.cfg`, cfg) - Server name, max players, password
- **Admins.cfg** (`SquadGame/ServerConfig/Admins.cfg`, cfg)

## Logs
- **SquadGame.log** (`SquadGame/Saved/Logs/SquadGame.log`)
