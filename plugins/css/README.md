# Counter-Strike: Source Dedicated Server

Dedicated server support for Counter-Strike: Source. Install, run, configure and monitor it from NodeGSM.

## Install
Installed with SteamCMD, app id [232330](https://steamdb.info/app/232330/info/).

## Defaults
| | |
|---|---|
| Game port | 27015 |
| Query port | 27015 |
| Max players | 24 |
| Query protocol | a2s |

## Config files
- **server.cfg** (`cstrike/cfg/server.cfg`, cfg) - Main server config (hostname, rcon_password, ...)

## Logs
- **Server logs** (`cstrike/logs/*.log`)

## Contributing
Found something outdated (exe path, ports, arguments)? Edit `plugin.json` and open a pull request - see [CONTRIBUTING.md](../../CONTRIBUTING.md).
